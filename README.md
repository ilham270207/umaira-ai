# Umaira AI

Umaira AI adalah asisten AI berbahasa Indonesia berbasis web. Bisa dipakai untuk mengobrol, membuat gambar, mengelola workspace, dan membuat dokumen, dengan mode tamu untuk mencoba sebelum mendaftar.

## V1.2
- Project-style dashboard
- Task detail panel
- Task priorities and estimates
- Progress tracking
- Recent project history
- Goal examples
- Responsive mobile UI
- Local demo mode with optional OpenAI integration and automatic fallback

## Run locally

```bash
npm install
npm start
```

Open http://127.0.0.1:3000

## Environment

Copy `.env.example` to `.env` if you want to enable optional OpenAI integration. Never commit `.env`.
